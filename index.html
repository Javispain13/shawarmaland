Capítulo 01

INSTALAR NEOFORGE

NeoForge permite que Minecraft cargue los mods. La versión debe coincidir con la del servidor.

1Descarga el instalador

Entra en la página oficial de descargas de NeoForge y busca la rama de Minecraft 1.21.1. Descarga el instalador recomendado para esa versión.

Abrir la web oficial de NeoForge ↗

No descargues instaladores de anuncios, páginas de terceros o botones falsos. Comprueba que estás en el dominio oficial.
2Ejecuta el instalador

Abre el archivo descargado. Si Windows pregunta con qué aplicación abrir un archivo .jar, necesitas tener Java instalado y asociado a los archivos JAR.

Selecciona Install client (instalar cliente), deja la carpeta de Minecraft correcta y pulsa aceptar/instalar.

Si aparece un error, comprueba que tienes Java 21 de 64 bits y que has elegido el instalador de Minecraft 1.21.1.
3Comprueba el perfil

Abre el launcher que uses y busca en la lista de instalaciones/versiones un perfil que indique NeoForge y 1.21.1. Selecciónalo y abre el juego una vez.

Cuando llegue al menú principal, puedes cerrarlo. Así se crean las carpetas necesarias.

Capítulo 02

INSTALAR LOS MODS

Este paso es igual para el launcher oficial y para TLauncher, siempre que estés usando la carpeta de juego correcta.

1Abre la carpeta AppData

Pulsa Windows + R para abrir Ejecutar. Escribe esta ruta y pulsa Enter:

%appdata%\.minecraft

Se abrirá la carpeta .minecraft, que contiene los archivos del juego.

2Busca o crea la carpeta mods

Dentro de .minecraft, busca una carpeta llamada mods. Si no existe, crea una carpeta nueva y ponle exactamente ese nombre: mods (en minúsculas).

3Copia los archivos del servidor

Descarga el paquete oficial de mods de ShawarmaLand desde este enlace: DESCARGAR MODS (Dropbox) ↗. Cuando termine la descarga, extrae el archivo .rar y copia los archivos .jar dentro de la carpeta mods.

No metas el archivo ZIP dentro de mods. Tampoco metas mods de Fabric, Forge o versiones distintas: deben ser compatibles con NeoForge 1.21.1.
4¡No añadas mods por tu cuenta!

Para evitar errores, utiliza exactamente el paquete que facilite el servidor. Algunos mods necesitan dependencias adicionales; si forman parte del paquete oficial, instálalas también.

Capítulo 03

ELIGE TU LAUNCHER

Sigue solamente el apartado que corresponda al launcher con el que juegas.

MINECRAFT PREMIUM

Launcher oficial

  1. Abre Minecraft Launcher oficial.
  2. Entra en Instalaciones.
  3. Busca el perfil de NeoForge 1.21.1 que creó el instalador.
  4. Si no aparece, revisa que NeoForge se instaló en la carpeta de juego que utiliza el launcher.
  5. Pulsa Jugar para iniciar esa instalación.
El launcher oficial suele utilizar %appdata%\.minecraft como directorio de juego predeterminado.
TLAUNCHER

Launcher de terceros

  1. Abre TLauncher y localiza el selector de versiones.
  2. Busca y selecciona la versión NeoForge 1.21.1 disponible en TLauncher.
  3. Inicia esa versión para que TLauncher prepare los archivos necesarios.
  4. No necesitas descargar por separado el instalador ni el cliente de NeoForge para este método: selecciona la versión NeoForge desde TLauncher.
  5. Abre la carpeta de juego que utiliza TLauncher y coloca allí los mods, en su carpeta mods. No des por hecho que coincide con %appdata%\\.minecraft.
Para TLauncher, sigue el método integrado de su selector de versiones: elige NeoForge 1.21.1 y no descargues aparte el cliente de NeoForge.
TLauncher no es el launcher oficial de Minecraft. Descárgalo únicamente desde su fuente legítima y revisa cuidadosamente los permisos y programas adicionales. La compatibilidad con perfiles instalados externamente puede variar.
Sobre el acceso: que el juego arranque con mods no garantiza que puedas entrar al servidor. La autenticación dependerá de cómo se configure el servidor. Si está en modo premium, necesitarás una cuenta legítima de Minecraft Java.

Cómo añadir el servidor

  1. Abre Minecraft con el perfil NeoForge 1.21.1 y el paquete de mods de ShawarmaLand.
  2. En el menú principal, pulsa Multijugador.
  3. Selecciona Añadir servidor.
  4. En «Nombre del servidor», escribe ShawarmaLand.
  5. En «Dirección del servidor», pega la IP que aparece abajo.
  6. Guarda y pulsa Entrar al servidor.

Solución de problemas

¿NO TE FUNCIONA?

?El juego se cierra al arrancar

Comprueba que utilizas Minecraft 1.21.1, NeoForge correspondiente y Java 21 de 64 bits. Revisa también que todos los mods sean para NeoForge y que no falten dependencias.

?No aparece la carpeta mods

Abre primero el perfil NeoForge una vez. Después vuelve a %appdata%\.minecraft. Si sigue sin aparecer, créala manualmente. Si usas TLauncher, comprueba su directorio de juego.

?Me dice que faltan mods o que son incompatibles

Tu instalación no coincide con la del servidor. Vuelve a descargar el paquete oficial y comprueba la versión exacta de NeoForge. No actualices mods individualmente por tu cuenta.

?No puedo conectarme al servidor

Comprueba que la IP está escrita correctamente, que el servidor está encendido y que tienes el paquete de mods correcto. Si aparece un mensaje de error, guarda una captura para que el equipo pueda ayudarte.
